# Example 04 — Custom Agent via OpenAI SDK

Demonstrates that Tsukuyomi works with any agent using the OpenAI Python SDK.
Just set `base_url`.

## Run

```bash
tsukuyomi start
python examples/04_custom_agent_openai_sdk/run.py
```

Tsukuyomi dashboard shows the request with `agent_hint=custom-agent/0.1`.
